05 / FEATURED Computer Vision

Citrus Detection & Ripeness Classification

My flagship project: a multi-stage pipeline that finds citrus fruit in dense orchard video, filters out leaves that get mistaken for unripe fruit, then classifies what's left as ripe or unripe. Rebuilt several times as real footage kept breaking assumptions the training data made.

  • YOLO11m fruit detector tuned for small, distant fruit (imgsz 1280) on merged Roboflow datasets, trained on an RTX A5000
  • Dedicated single-class leaf detector to suppress false positives from dense foliage read as unripe fruit
  • Ripeness call moved from a hand-tuned HSV heuristic to a trained YOLO classifier for more reliable results
  • Iterated through multiple dataset sources and self-labeled video frames to close the training-to-real-footage gap
YOLO11 PyTorch OpenCV Agritech Computer Vision

06 Computer Vision

Annoying Alarm

A gesture-verified alarm system that stays active until a real-time computer vision pipeline confirms the user has physically completed a set of jumping jacks, enforcing accountability before the alarm can be disarmed.

  • Built a real-time pose-estimation pipeline with MediaPipe BlazePose, tracking 33 body landmarks from a live webcam feed
  • Designed a joint-angle state machine to classify exercise repetitions from raw landmark coordinates, with noise-tolerant thresholding to minimize false negatives from occlusion and motion blur
  • Developed a Tkinter desktop application handling the full alarm lifecycle — scheduling, live countdown, embedded video overlay, and automatic disarm on rep completion
  • Implemented fault-tolerant video capture with backend fallback and dropped-frame recovery, plus a file-based input mode for reproducible testing and demos
